# naver_paste — 네이버 블로그 원고 붙여 넣기 스크립트

마크다운으로 쓴 원고를 네이버 블로그 편집기에 문단씩 붙여 넣습니다.
사람이 메모장에서 문단을 복사해 붙이는 것처럼, 맥의 진짜 키보드 입력을 씁니다.

- 제목, 문단, 굵은 소제목, 사진을 넣습니다.
- 문단 사이에 빈 줄을 넣고, 문단마다 몇 초씩 쉬어 갑니다.
- **발행 버튼은 누르지 않습니다.** 사진 설명, 태그, 발행은 직접 확인하고 누르세요.

## 필요한 것

- macOS, Google Chrome, Python 3 (맥에 기본으로 들어 있습니다)
- 따로 설치할 라이브러리는 없습니다.
- 스크립트를 돌리는 터미널 앱에 **손쉬운 사용** 권한
  (시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용)

## 원고 형식

```markdown
# 제목

첫 문단입니다. 한 줄이 한 문단이 됩니다.

## 소제목은 굵게 들어갑니다

**이렇게 써도 굵게 들어갑니다**

![사진 설명](사진.png)

#태그1 #태그2
```

- 첫 번째 `# ` 줄이 제목입니다.
- `## 소제목`이나 `**소제목**` 줄은 굵게 들어갑니다.
- 사진은 png만 됩니다. 경로는 원고 파일이 있는 폴더 기준입니다.

## 쓰는 순서

1. 크롬에서 네이버 블로그 글쓰기 화면을 엽니다.
2. 짧은 시험 글로 먼저 확인합니다.
   ```
   python3 naver_paste.py --sample
   ```
3. 8초 안에 크롬 편집기의 **제목 칸**을 클릭하고, 손을 뗍니다.
4. 시험 글이 잘 들어가면 지우고, 내 원고로 돌립니다.
   ```
   python3 naver_paste.py 내원고.md --dry   # 어떻게 나뉘는지만 확인
   python3 naver_paste.py 내원고.md
   ```
5. 끝나면 사진 설명을 넣고, 태그를 확인하고, 발행합니다.

## 주의

- **실행 중에는 맥을 만지지 마세요.** 키보드 입력이 다른 창으로 새면 그 창에 글이 들어갑니다.
  그래서 크롬이 맨 앞에서 내려가면 스크립트가 바로 멈추게 해 두었습니다.
  Finder 창은 닫고 시작하는 편이 안전합니다.
- 멈추려면 터미널에서 `Ctrl+C`를 누르세요.
- 이 스크립트는 붙여 넣기만 도와줍니다. 네이버의 운영 정책을 대신 지켜 주지는 않습니다.
  글은 직접 쓰고, 발행은 직접 누르고, 하루에 몇 편씩 몰아 올리지 마세요.

## 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 아무것도 안 들어간다 | 터미널 앱의 손쉬운 사용 권한을 켜고 터미널을 다시 시작 |
| "멈춤: 맨 앞 창이 크롬이 아니라…" | 크롬 편집기를 앞으로 띄우고 처음부터 다시 |
| 본문이 제목 칸에 들어간다 | 시작할 때 제목 칸을 클릭했는지 확인 |
